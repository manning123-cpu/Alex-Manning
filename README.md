# Alexander Manning — Personal Website

Single-page portfolio website built with Next.js 14 for Alexander Manning, a UCLA Environmental Science student focused on environmental consulting, climate strategy, climate tech, and long-term climate VC.

## Stack

- Next.js 14 (App Router)
- Tailwind CSS + custom CSS variables
- Framer Motion animations
- Lucide React icons
- `next/font` with Playfair Display + DM Sans

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production Build

```bash
npm run build
npm run start
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import the GitHub repository.
4. Vercel will detect Next.js automatically.
5. Keep default settings and click **Deploy**.
6. Add custom domain (optional) in Project Settings → Domains.
